# Good Nearby — V1 prototype

Mobile-first static prototype for **Good Nearby — The local guide for dog people**.

### V1 flows
- Find something near me
- Find something to do
- Build My Dog Day
- Search + category filters
- Save places
- Event discovery
- Verification/restriction badges
- Responsive mobile navigation

### Deploy
Upload this folder to Netlify or connect the repo to Netlify.

### Next production layer
1. Replace seed data with the master Good Nearby database.
2. Add real map + geolocation/ZIP search.
3. Add current status, last verified, and sources.
4. Add reporting/update workflow.
5. Persist Saved + Dog Days.
6. Expand city-by-city.

**Important:** Dog access should never be inferred merely from outdoor seating or proximity to a dog park.
